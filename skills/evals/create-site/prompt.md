Создай сайт Keelkit по спецификации site.yaml в текущем каталоге — скиллом keelkit:create-site.

Это автоматический прогон (эвал): человека нет, вопросов не задавай и ответов не жди — где скилл предлагает план,
выбирай умолчания скилла и работай дальше. Скилл строит сайт по шагам плана (`PLAN.md`), по шагу за сессию; здесь
сделай фазу «План» и затем все шаги плана подряд в этой же сессии, не останавливаясь между ними. Эталон бери из локального клона монорепо (переменные KEELKIT_REPO и
KEELKIT_REF уже заданы). Сайт должен пройти все проверки шага «Проверка» скилла, включая браузерные тесты;
в конце всё закоммить в локальный git и не оставляй запущенных серверов.
